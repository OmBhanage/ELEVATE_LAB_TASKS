# Java Console Calculator

## About
This is a simple calculator program made using Java
It performs basic arithmetic operations through the console
## Features
- Addition
- Subtraction
- Multiplication
- Division
- Exit option
- Handles division by zero
- Can perform multiple calculations
## Concepts Used
- Java class and methods
- Scanner for user input
- if-else statements
- while loop
- Basic arithmetic operations
## How to Run
1. Open the project in vs code and run using run code
